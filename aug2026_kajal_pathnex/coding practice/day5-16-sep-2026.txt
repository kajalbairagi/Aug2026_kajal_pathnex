## ansible - Create User and set permissions

---
- name: create new user
  hosts: all
  become: yes
 
tasks:
  - name: create User
    user:
      name: pathnex
      state: present 
      shell: /bin/bash
  
  - name: Set permissions for the user
    file:
      path: /home/pathnex
      owner: pathnex
      group: pathnex
      mode: '0755'
